# Лабораторная работа №9: Автокодировщики (Autoencoders) в TensorFlow и PyTorch

## Тема работы
**Изучение архитектуры автокодировщиков и их применение для сжатия данных, обучения признаков и восстановления изображений**

## Цель работы
Освоить принципы построения и обучения автокодировщиков (autoencoders) для решения различных задач обработки изображений, включая:
- Сжатие данных через обучение латентному представлению
- Визуализацию скрытого пространства признаков
- Восстановление изображений после их искажения

## Содержание работы

### Задание №1: Базовый автокодировщик (tf/tf_lite.ipynb)
**Цель:** Построить автокодировщик с 2-мерным латентным пространством и визуализировать разделение классов цифр.

**Задача:** 
- Обучить автокодировщик на выборке цифр 0, 1, 3
- Добиться ошибки MSE < 0.034 на 10-й эпохе
- Визуализировать расположение цифр в латентном пространстве

**Архитектура:**
- Encoder: сверточные слои → Flatten → полносвязный слой (2 нейрона)
- Decoder: полносвязный слой → reshape → трансposed свертки

### Задание №2: Автокодировщик для конкретного класса (tf/tf_pro.ipynb)
**Цель:** Обучить автокодировщик для восстановления изображений цифры 5.

**Задача:**
- Выбрать 10 наиболее "красивых" изображений цифры 5
- Создать датасет, где оригинальные изображения сопоставляются с выбранными "красивыми" примерами
- Обучить автокодировщик, добиваясь MSE < 0.05
- Проанализировать качество восстановления

### Задание №3: Денойзинг изображений (tf/tf_ultra_pro.ipynb)
**Цель:** Научить автокодировщик восстанавливать изображения, поврежденные черными квадратами.

**Задача:**
- Добавить на изображения MNIST случайные черные квадраты (8×8)
- Обучить автокодировщик восстанавливать оригинальные изображения из зашумленных
- Добиться MSE < 0.0070 на тестовой выборке

**Архитектура:**
- Encoder: несколько сверточных слоев с пулингом
- Decoder: трансposed свертки для восстановления разрешения

### Задание №4: PyTorch версия (pytorch/pytorch_lite.ipynb)
**Цель:** Реализовать базовый автокодировщик с 2D латентным пространством на PyTorch.

**Задача:**
- Перенести архитектуру из задания №1 на PyTorch
- Обучить модель на тех же классах (0, 1, 3)
- Визуализировать латентное пространство

## Ключевые концепции

- **Автокодировщик (Autoencoder):** Нейронная сеть, состоящая из encoder (сжимает данные) и decoder (восстанавливает данные)
- **Латентное пространство:** Сжатое представление данных в низкомерном пространстве
- **MSE (Mean Squared Error):** Метрика качества восстановления изображений
- **Свёрточные слои:** Эффективны для работы с изображениями благодаря учету локальной структуры
